### 3.1 users

Stores every account of the system (Student, Parent, Moderator, Administrator, Consulting Center) and the account-level flags used by authentication, the age policy and forum moderation.

| Column | Type | Constraints | Notes |
| :---- | :---- | :---- | :---- |

| email | VARCHAR(256) | NOT NULL, UNIQUE | Log-in identifier; stored in lower case; unique index used by log-in and registration |

| full_name | VARCHAR(128) | NOT NULL | Display name |
| role | VARCHAR(16) | NOT NULL | student \| parent \| center \| moderator \| admin; Student or Parent is chosen at registration, the other roles are created by an Administrator or Moderator; copied into the JWT role claim |

| parent_acknowledged | BOOLEAN | NOT NULL | Legacy flag (old "parent knows" tick box), kept because data exists; replaced by parent_student_links |

### 3.2 user_sessions

Server-side record of every issued JWT, so a token can be revoked before it expires (log-out, password change, administrator lock).

| Column | Type | Constraints | Notes |
| :---- | :---- | :---- | :---- |
| id | UUID | PRIMARY KEY | Generated by the application (Guid) |
| user_id | UUID | NOT NULL, FOREIGN KEY → users(id) ON DELETE CASCADE | Owner of the session; composite index (user_id, is_revoked) |
| token_hash | VARCHAR(64) | NOT NULL | SHA-256 hash (hex, 64 chars) of the JWT; indexed and checked on every authenticated request; the raw token is never stored |
| expires_at | TIMESTAMPTZ | NOT NULL | Same expiry as the JWT (7 days) |
| is_revoked | BOOLEAN | NOT NULL | TRUE after log-out, password change or account lock; the request then gets 401 |
| ip_address | VARCHAR(64) | NULL | Client IP at log-in (IPv4 or IPv6), taken from X-Forwarded-For behind Nginx |
| user_agent | VARCHAR(512) | NULL | Browser / client identification string |
| created_at | TIMESTAMPTZ | NOT NULL | Time the row was created (UTC) |
| updated_at | TIMESTAMPTZ | NULL | Last change time (UTC) |

**Other indexes and constraints:** index `ix_user_sessions_token_hash` on (token_hash); index `ix_user_sessions_user_id_is_revoked` on (user_id, is_revoked)
