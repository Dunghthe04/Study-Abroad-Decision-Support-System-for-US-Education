PostgreSQL 16 with the pgvector extension, schema `app`. The model has **51 tables** in eight groups. Primary keys are UUIDs generated by the application (the only exceptions are the composite keys of the two junction tables and `state_living_costs.state_code`). All timestamps are `TIMESTAMPTZ` and stored in UTC. The EF Core table `__ef_migrations_history` records applied migrations and is not part of the domain model.
